## Article, newsletter and feed post are different objects

A standalone article is a long-form publication without membership in a newsletter series. A newsletter is a named, subscribable series; each edition is still an article, attached to that series. An announcement feed post is a separate short-form object linking to the edition. A `/pulse/` URL or an “article” label alone does not distinguish standalone articles from newsletter editions.
