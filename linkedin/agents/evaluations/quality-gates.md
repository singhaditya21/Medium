# LinkedIn agent quality gates

Before an item appears in an approval brief, verify:

1. **Relevance:** it connects directly to the user's established topics or a specific relationship objective.
2. **Context:** the source post, thread, or profile has been read sufficiently to avoid a generic response.
3. **Novelty:** the user has not already made the same point in the thread or recently to the same person.
4. **Evidence:** the proposal identifies a concrete source fact, metric, claim, or operating tension.
5. **Relationship timing:** it does not violate the watchlist's waiting or no-follow-up rules.
6. **Safety:** it contains no private data, credentials, browser state, or private URL.
7. **Approval readiness:** exact text, exact destination, intended mention, and reason are all visible to the user.

Fail any gate: do not queue the action.
